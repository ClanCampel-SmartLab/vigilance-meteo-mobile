# Historique

## 0.1.0-beta.3

- Liens API dans les formulaires de clé et aide Companion accessible.
- Liste ciblée des capteurs géocodés, statut lisible et écran d'aide sans capteur/action.
- Nom facultatif ; nom du téléphone par défaut.
- Plusieurs destinations par position, avec avertissement et déduplication par destination.
- Ajout/modification/retrait de profils et récapitulatif avant enregistrement.
- Fiches virtuelles par profil, bouton de test individuel et bouton d'actualisation commun.
- Attributs détaillés de vigilance, phénomènes/horaires et dernier test.
- Exemple de carte native avec confirmation avant envoi de test.
- Migration prévue de la configuration bêta 2 sans effacer la clé ni les identifiants de profil.
- Pas de confirmation frontend de fermeture : avertissements uniquement, limitation explicite.
- Documentation et tests enrichis ; version expérimentale à valider dans un vrai Home Assistant.

## 0.1.0-beta.2

Première bêta publiée : configuration graphique, notifications dynamiques, API partagée, seuils et exclusions facultatives.
