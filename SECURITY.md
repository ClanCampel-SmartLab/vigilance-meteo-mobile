# Sécurité

Ne pas inclure de clé API, sauvegarde Home Assistant, adresse ou position dans un ticket public.
Si une clé est exposée, la révoquer immédiatement auprès de Météo-France et reconfigurer l'intégration.
Utiliser le mécanisme privé de signalement GitHub s'il est activé par le propriétaire ; sinon ne pas publier de détails exploitables publiquement.
Le logiciel n'est pas un système de sécurité ou d'alerte garanti.
