# Sécurité

Ne pas partager de clé, adresse, coordonnées, .storage ou sauvegarde dans un ticket public.
Révoquer immédiatement une clé exposée. Protéger Home Assistant et les sauvegardes.
Le logiciel ne constitue pas un système d'alerte de sécurité garanti.
Utiliser le signalement privé GitHub si activé pour une vulnérabilité, sans publier de détails exploitables.
